# Migrieren der Benutzerverwaltung zur Adobe Admin Console

Wenden Sie sich an Ihr Adobe-Account-Team, um den Übergang von geeigneten Lösungen zur zentralisierten Benutzerverwaltung über die Adobe Admin Console zu besprechen.

Bevor Sie sich an Ihr Adobe-Account-Team wenden, überprüfen Sie, ob Ihr Unternehmen die Eignungsanforderungen erfüllt, und ermitteln Sie die Stakeholder, die an der Migrationsplanung teilnehmen.

Die Migrationsberechtigung variiert je nach Lösung. Bevor Sie mit dem Migrationsprozess beginnen, stellen Sie sicher, dass Ihre Organisation über Folgendes verfügt:

- Eine geeignete Unternehmenslösung oder -bereitstellung, die die Migration zur Adobe Admin Console-basierten Benutzerverwaltung unterstützt.
- Zugriff auf die Adobe Admin Console, sofern zutreffend.
- Administratorzugriff erforderlich, um Ihre aktuelle Benutzerverwaltungskonfiguration zu überprüfen.
- Kontaktinformationen für Ihr Adobe-Account-Team oder einen Implementierungsbeauftragten.
- Alle lösungsspezifischen Voraussetzungen wurden erfüllt, falls zutreffend.

## Überprüfen der Eignung und Anfordern der Migration

1. Überprüfen Sie Ihre aktuelle Lösungskonfiguration und stellen Sie sicher, dass sie die Migration zur Adobe Admin Console-basierten Benutzerverwaltung unterstützt.
2. Überprüfen Sie alle lösungsspezifischen Eignungsanforderungen und Voraussetzungen.
3. Wenden Sie sich an Ihr Adobe-Accountteam und fordern Sie die Migration zur Adobe Admin Console-Benutzerverwaltung an.
4. Arbeiten Sie mit Ihrem Adobe-Account-Team zusammen, um den Zeitplan für die Migration, die Implementierungsanforderungen und die organisatorische Bereitschaft zu überprüfen.
5. Informieren Sie betroffene Administratoren und Benutzer über alle Anmelde- oder Zugriffsänderungen.

## Nach der Migration

Nach Abschluss der Migration:

- Die Benutzerverwaltung erfolgt über die Adobe Admin Console.
- Die Benutzeranmeldung und der Zugriff können je nach Identitätskonfiguration des Unternehmens aktualisiert werden.
- Laufende User Lifecycle Management-Aktivitäten sollten über die Adobe Admin Console durchgeführt werden, sofern für die Lösung keine anderen Dokumente vorliegen.

Wenn Ihr Unternehmen die Eignungskriterien nicht erfüllt, wenden Sie sich an Ihr Adobe-Accountteam, um Möglichkeiten zu erkunden, wie Sie sich für die Adobe Admin Console-Benutzerverwaltung qualifizieren können.
