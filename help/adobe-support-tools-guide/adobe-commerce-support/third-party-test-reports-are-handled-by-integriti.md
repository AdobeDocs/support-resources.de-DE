# Wie melde ich eine Sicherheitslücke, die von einer Sicherheitsagentur eines Drittanbieters entdeckt wurde?

In diesem Artikel wird erläutert, wie Sie eine Sicherheitslücke melden, die von einer Sicherheitsagentur eines Drittanbieters gefunden wurde, und welche Sicherheitsberichte Adobe verarbeitet.

## Betroffene Produkte und Versionen

Adobe Commerce (alle Versionen)

## Problem

Ein Händler führt einen PEN-Test über eine unabhängige Sicherheitsagentur durch und der Test kennzeichnet eine Sicherheitslücke.

## Lösung

Um eine Sicherheitslücke zu melden, senden Sie sie an [[!DNL Intigriti]](https://app.intigriti.com/programs/adobe/adobepublic/detail). Adobe Commerce verfügt über keinen direkten Ansprechpartner bei Intigriti. Wenden Sie sich daher bei Fragen direkt an [!DNL Intigriti].

Adobe prüft und verarbeitet nur Berichte, die vom Magento Security Scan Tool (MST) generiert wurden. Adobe unterstützt keine Berichte von Sicherheits-Scan-Tools anderer Anbieter.
